Mapbox markers and popups in this repo

A quick sheet for the current stack: react-map-gl@8.1.3 on top of mapbox-gl@3.31.0. Use this when you need to remember where a behavior lives before editing app/locations/locations-map.tsx.

Mental model
Marker A geographic anchor plus optional custom DOM. In this repo the SVG pin is the marker content.
Popup Separate UI rendered at coordinates. It is shown or hidden by React conditions, not by the marker automatically.
State Hover and selection decide whether the popup exists. Marker click forwards selection to the parent.

Change marker color, size, ring, or animation <Marker> child DOM SVG classes, wrapping div classes, or marker child markup
Change popup location relative to the pin <Popup> props anchor, offset
Change popup width or styling <Popup> props and popup body maxWidth, className, inner markup
Open popup on click instead of hover React state and event handlers hoveredMarker, selectedParkrunId, onClick, hover handlers
Close popup when map moves or user clicks elsewhere <Popup> other props closeOnClick, closeOnMove, onClose
Need imperative control React ref to Marker or Popup Use native methods like togglePopup() or trackPointer()
Current repo behavior
  • Parkrun markers render custom SVG pins inside <Marker>.
  • Parkrun popups render when a marker is hovered or selected.
  • Home markers have a separate hover-driven popup.
  • Marker click stops propagation and forwards the selected Parkrun to the parent.
  • The popup body is plain React markup, so content changes are regular JSX changes.
